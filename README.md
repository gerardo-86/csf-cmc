# csf-cmc

Espejo de los instaladores de CSF (ConfigServer Security & Firewall) y CMC (ConfigServer Mail Manage/Cluster) para el aprovisionamiento de VPS.

- Versión de CSF: 14.24
- Origen: https://github.com/jeni159/public-files (commit aeefab8)
- Licencia: CSF es software libre bajo GPLv3; se redistribuye sin modificaciones.

## Descarga

```
wget https://raw.githubusercontent.com/gerardo-86/csf-cmc/main/csf.tgz
wget https://raw.githubusercontent.com/gerardo-86/csf-cmc/main/cmc.tgz
```
